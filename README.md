# python-junior-level-herve
Il sagit de l'enssemble des fichiers utilises aucour de la formation d'initiation au language de programmation python 

# Structure
Le cour se divise en 7 grandes parties qui sont :
- 1. Introduction
- 2. Controle flux d'execution
- 3. Instructions repetitives
- 4. Principaux types de donnees
- 5. Fonctions predefinies
- 6. Fonctions originales
- 7. Approfondir les structures de donnees

# Remarque
Nous pourrons rajouter au fur et a mesure d'autres modules en fonction des besoins et de la necessite

Chacune des parties contient plusieurs fichiers

Chaque fichier se compose :
- de contenu de cour
- d'exercise pratique
- des liens utiles

Le cour se deroule comme suit : 
- on lit le cour contenu dans chaque fichier
- on s'arrete a des moments cles pour proceder a une explication du cour
- on traite les exercises pratiques
- on programme les exercises a faire plutard
